---

## 🛠️ Tecnologías Utilizadas

* **React.js** - Biblioteca de UI.
* **Tailwind CSS** - Estilizado rápido y responsivo.
* **AOS (Animate On Scroll)** - Animaciones sutiles en la navegación.
* **EmailJS** - Gestión de contacto directamente desde el cliente.
* **React Icons** - Set de iconos premium.

## 🎨 Diseño
El proyecto sigue una estética **Minimalist**:
- Esquema de colores blanco y negro.
- Tipografías sans-serif pesadas para jerarquía.
- Enfoque total en la legibilidad y la experiencia de usuario (UX).

## 📦 Instalación y Setup

Si querés correr este proyecto localmente:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Gu1ll3rm04r13l/Portfolio.git
2. Instalá las dependencias:
   ```bash
   npm install

3. Corré el servidor de desarrollo:
   ```bash
    npm run dev
